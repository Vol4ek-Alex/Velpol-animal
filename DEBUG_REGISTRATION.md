# 🔧 Диагностика ошибки "Database error saving new user"

## 📋 ИНСТРУКЦИЯ ДЛЯ ДИАГНОСТИКИ:

### Шаг 1: Откройте Developer Tools

1. Откройте **сайт** в браузере
2. Нажмите **F12** (или Ctrl+Shift+I)
3. Перейдите на вкладку **Console**

### Шаг 2: Попробуйте зарегистрироваться

1. Выберите модуль (Агрономия или Животноводство)
2. Нажмите **Регистрация**
3. Заполните форму
4. Нажмите **Зарегистрироваться**

### Шаг 3: Посмотрите ошибку в Console

Вы должны увидеть что-то вроде:
```
Supabase Auth Error: {
  status: 422,
  message: "...",
  ...
}
```

**Скопируйте ТОЧНЫЙ текст ошибки и дайте мне!**

## 🔍 ВОЗМОЖНЫЕ ПРИЧИНЫ:

### ❌ Проблема 1: Email уже зарегистрирован
```
Error: User already exists
```
**Решение:** Используйте новый email при регистрации

### ❌ Проблема 2: Неверный формат email
```
Error: Invalid email format
```
**Решение:** Проверьте что email написан правильно (example@mail.com)

### ❌ Проблема 3: Пароль слишком слабый
```
Error: Password is too weak
```
**Решение:** Пароль должен быть минимум 6 символов

### ❌ Проблема 4: Ошибка конфигурации Supabase
```
Error: Invalid configuration
```
**Решение:** Проверьте ключи в `js/config.js`

### ❌ Проблема 5: RLS политики блокируют
```
Error: new row violates row-level security policy
```
**Решение:** Проверьте RLS политики в Supabase
